## 城市地铁管理和查询系统数据文件

格式:

LINE|线路名称|全程票价|首班时间|末班时间|站点1,站点2,站点3,...

站点间的距离（或时间权重）简化为 3.0 (单位: 分钟)

换乘站点的名称需确保一致

LINE|1号线|7.0|06:30|23:00|罗湖,国贸,老街,大剧院,会展中心,购物公园,车公庙,世界之窗,新安
LINE|4号线|7.0|06:30|23:00|福田口岸,福民,会展中心,市民中心,深圳北站,清湖
LINE|7号线|6.0|06:20|23:20|西丽湖,西丽,茶光,珠光,车公庙,石厦,福民,皇岗口岸
LINE|11号线|10.0|06:00|23:30|福田,车公庙,后海,前海湾,宝安,机场,沙井,松岗,福永
LINE|9号线|6.0|06:25|23:10|文锦,人民南,老街,红岭,大剧院,红树湾南,深圳湾公园



### 注意！在windows环境下使用GBK编码，需要在main函数中添加 “ SetConsoleOutputCP(65001); ”  才可正常在控制台输出



扩展功能（可选）：

1. 站点间的真实距离/时间信息（目前简化为3.0）

2. 线路颜色

3. 票价计算函数（目前简化为线路全程票价）

4. 更多换乘信息 (例如：换乘通道所需时间)
